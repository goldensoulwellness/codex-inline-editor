Start in three steps

  1. Open your webpage and click the tiny pencil at the top right. Reload tabs that were open before installation.
  2. Click the words you want to change and type. Click another text section to keep editing. A purple outline marks the active section.
  3. Click Copy edits, then paste the compact replacement instructions into the Codex chat for your source project.

The extension changes your browser's view. Your source files and published website change only after you apply and release the edits through your normal workflow.

Keyboard and recovery

Open the editor, then Tab to text and press Enter. Escape finishes the current section. The × discards unsent changes. Drafts survive a reload in the same tab while the browser stays open; closing the tab or restarting the browser clears them. Copy important drafts before reconnecting, navigating away, or closing.

Optional: Send directly to a chat

Copy works immediately. Direct Send requires the separate local companion, Node.js 20 or later, and a Codex installation whose CLI supports codex queue. It does not require an API key.

  1. Download the local companion. Extract the folder. Keep connect.mjs, protocol.js, and package.json together.
  2. In the Codex chat for your website, ask Codex to run the following with the actual URL and source directory. It must use that chat's CODEX_THREAD_ID, or its exact verified UUID via --thread.
node /path/to/companion/connect.mjs   --target https://your-website.example/page   --project /absolute/path/to/website-source

Codex should verify the returned thread and project, then open the returned connectionURL in the intended tab. The extension pairs that tab and returns to the original webpage. Keep the companion running.

Every new tab needs its own connection. A browser extension cannot infer which Codex chat contains a tab. Never reuse another chat's paired tab. A browser restart clears connections. The Send button appears after an edit in a connected tab.

Send includes the page URL, source project, selectors, and exact before/after text. It queues one request in the connected chat. Codex processing can take time. If delivery is uncertain, check the chat before retrying; your draft stays available.

Supported pages

Ordinary HTML text on HTTP and HTTPS webpages, including local development previews. Protected browser pages, the Chrome Web Store, PDFs, canvas text, nested frames, and text inside other shadow roots are not supported. Existing form fields and rich-text editors are left alone. Some site layouts or framework rerenders may be incompatible.

The toolbar is a webpage-based strip styled separately from the page; it is not native browser chrome. Website scripts remain active. Use the extension on pages you own or are authorized to edit.

Troubleshooting and support

If the pencil is missing, confirm the extension is enabled for this site and reload after copying any drafts. If Send is unavailable, reconnect this exact tab from its intended Codex chat with the local companion running. For an uncertain Send result, check the chat before retrying. For other questions, use the developer contact on the Chrome Web Store listing; do not include private text, tokens, or account credentials.

Turn automatic loading off

Open the extension popup and turn off “Show pencil automatically.” Copy any draft first, then reload. You can also restrict site access or disable the extension in your browser's extension manager.
